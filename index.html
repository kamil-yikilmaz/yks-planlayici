💡 GitHub Pages'da Nasıl Çalışır? (CORS & Sunucu Rehberi)

1. Bulut Açık Kaynak (En Kolayı - Sıfır Kurulum):
Groq Cloud veya OpenRouter seçip ücretsiz bir API anahtarı girin. Llama 3.3 70B veya Qwen 2.5 gibi devasa açık kaynak modeller GitHub Pages'tan doğrudan çalışır.

2. Yerel Bilgisayarda Ollama (CORS Ayarı):
GitHub Pages (HTTPS) yerel Ollama'ya bağlanırken CORS iznine ihtiyaç duyar. Terminalde bir kez şu komutla çalıştırın:
$env:OLLAMA_ORIGINS="*" ; ollama serve (Windows PowerShell)
OLLAMA_ORIGINS="*" ollama serve (Mac/Linux)

3. LM Studio:
LM Studio -> Local Server sekmesi -> "Enable CORS" kutucuğunu işaretleyin.
